Mittal Associates & Architecture — GitHub Pages + Custom Domain Setup
=========================================================================

1. Extract this ZIP file so `index.html` and all 19 other `.html` files + `assets/` are at the root of your repository.
2. Optional: add your own custom domain in GitHub Pages settings after publishing; do not add a CNAME unless you own and have configured that domain.
3. Push all files to your GitHub repository (`main` branch).
4. In GitHub: go to Settings -> Pages -> Source: Deploy from a branch -> Branch: `main` / `/ (root)` -> Save.
5. Add DNS records at your domain registrar pointing to GitHub Pages (`185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153` for apex domain, or CNAME to `<username>.github.io` for `www`), then enable "Enforce HTTPS".
